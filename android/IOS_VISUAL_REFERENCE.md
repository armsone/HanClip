## 공통 시각 언어

- 아주 옅은 청록 배경과 흰색에 가까운 상단 그라데이션
- 짙은 남청록 글자·아이콘, 청록 선택 상태, 낮은 대비의 회청록 테두리
- 큰 캡슐 버튼과 둥근 사각 카드, 얇은 외곽선, 절제된 그림자
- 섹션 제목은 작은 청록 아이콘 배지와 함께 오른쪽 또는 카드 시작선에 정렬
- iOS 상태바와 안전 영역을 포함한 실제 화면 비율을 기준으로 비교

## 현재 Android와 우선 교정할 차이

1. 홈: iOS의 중앙 아이콘형 2열 프리셋 카드, 순서 `새 영화 → AiShot → 여행 영화 → 골프 영화`, 상단 추가 버튼, 영화 목록 헤더 구조로 교정한다.
2. AiShot: 상단 검정 제어부·중앙 카메라·하단 검정 제어부의 3단 구조와 `.5/1/2/4/8` 줌, 감도 순서를 맞춘다.
3. 영화 제작: iOS의 압축된 설정 표, 클립 목록, 고정 하단 제작 버튼 구조를 기준으로 재배치한다.
4. 달력·미디어 선택: iOS의 전용 7열 달력, 날짜별 미디어 썸네일, 사진/Live/영상 필터와 하단 날짜 이동 버튼을 기준으로 맞춘다.
5. 카피라이터: 플랫폼 2×5 그리드, 위치 5×5, 색상·그림자·화면 꺼짐 방지 카드 구조를 동일하게 구성한다.

픽셀 절댓값 대신 안전 영역을 제외한 화면 폭 비율과 구성 요소 비율도 함께 비교한다.

# HanClip Ai Learning Notes

HanClip Ai의 목적은 소리 자체를 맞히는 것이 아니라 영상에서 가장 행복하고, 가장 흥분되고, 꼭 기억해야 할 순간을 찾는 것이다.

`Tools/PhotosAiStudy.swift`는 영상 파일의 오디오만 읽어 순간 피크, 직전 대비 상승, 이후 반응 지속을 요약한다. 원본 영상과 식별자는 저장하지 않고, 해시와 숫자 특징만 남겨 Ai 기준을 조정하는 데 쓴다.

Photos 보관함 전체를 공부할 때는 macOS의 Photos 권한이 필요하다. 권한이 막혀 있으면 Photos에서 영상 원본을 별도 폴더로 내보낸 뒤 `--input-directory`로 분석할 수 있다.

2026-08-06 학습 메모:

- Photos의 `video` 검색 결과에서 798개 영상을 임시로 내보내 분석했다.
- 원본 영상은 분석 뒤 임시 폴더에서 삭제했고, 숫자 요약만 `docs/ai-learning/`에 남겼다.
- 상위 순간들은 단순히 가장 큰 소리보다 직전 대비 상승과 이후 반응 지속이 함께 나타나는 경우가 많았다.
- 이 결과를 반영해 HanClip Ai는 영상 시작/끝의 착시 점수를 낮추고, 피크 뒤에 실제 반응이 이어지는 순간을 더 잘 보도록 조정했다.
- 생활/여행 영상에서 순간 잡음만으로 하이라이트가 과대평가되지 않도록, 피크 뒤의 반응 에너지가 충분할 때만 지속 반응 점수를 더 믿게 했다.
- 798개 기준 누적 요약: 영상 798개, 후보 순간 8,195개, 평균 길이 약 28.2초, 평균 피크 점수 1.454, 평균 후보 점수 0.479.
- 화면 요약 도구를 추가했다. 원본 프레임은 저장하지 않고, 움직임 평균/최대값과 밝기 변화 평균/최대값만 남겨 AiShot의 화면 보조 판단을 검증하는 데 쓴다.
- 전체 798개 화면 포함 재분석 기준: 평균 움직임 0.145, 최대 움직임 0.877, 평균 밝기 변화 0.029, 최대 밝기 변화 0.877.

온라인 관찰 메모:

- 공개된 Instagram/YouTube 크리에이터 안내와 숏폼 편집 자료를 참고했다. 계정에 남는 행동, 다운로드, 저장, 좋아요, 댓글, 팔로우, 공유는 하지 않는다.
- 공통 패턴은 첫 순간의 강한 훅, 즉시 보이는 결과나 움직임, 예상을 깨는 전환, 짧은 설명 뒤의 반응 지속이다.
- HanClip Ai에는 특정 플랫폼 데이터를 가져오지 않고, "소리 변화 + 화면 변화 + 이후 반응"이라는 추상 기준으로만 반영한다.
- 참고한 공개 자료: Meta Instagram Best Practices, Instagram Insights Help, YouTube Shorts/숏폼 retention 관련 공개 자료.

Ai 버전 기록:

- 0.1.0: 소리 중심 Ai. 티샷, 박수, 갑자기 좋아지는 순간, 이어지는 반응을 소리 기준으로 찾는 첫 기준이다.
- 0.2.0: 소리 + 화면 보조 Ai. AiShot 실시간 촬영에서 화면의 움직임과 밝기 변화도 가볍게 참고한다. 화면만으로 촬영을 결정하지 않고, 소리 판단이 애매할 때 확신을 보태는 역할로 둔다.
- 0.2.1: 798 영상 보정 Ai. Photos 영상 전체 공부 결과와 화면 요약 도구를 반영한 보정판이다. 큰 소리 자체보다 피크 뒤에 실제 반응이 이어지는지, 화면 변화가 함께 있는지를 더 차분하게 본다.
- 롤백 기준: 새 Ai가 불안정하면 `AudioImpactClassifier.currentModelVersion`을 이전 버전으로 되돌려 같은 앱 안에서 이전 기준을 다시 선택할 수 있게 한다.

Instagram 관찰 메모:

- 계정에 남는 행동 없이 릴스 화면을 열고 스크롤로만 일부 인기 흐름을 관찰했다.
- 원본 영상 다운로드, 저장, 좋아요, 댓글, 팔로우, 공유는 하지 않았다.
- 인기 짧은 영상은 초반 훅, 짧은 상황 설명, 예상과 다른 반전, 웃음이나 당황 반응이 이어지는 구조가 많았다.
- HanClip Ai에는 특정 플랫폼의 원본 데이터가 아니라 “갑자기 좋아진 순간 뒤에 반응이 이어지는가”라는 추상 기준으로만 반영한다.
